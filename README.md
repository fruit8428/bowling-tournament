# 🎳 國際扶輪 3523 地區保齡球聯誼賽 即時計分看板 (v3 雲端版)

比賽當天使用：記分員用手機（4G/5G 即可）拍照或手動登錄各球道成績，大螢幕看板與排行榜即時更新。

## 架構

| 層 | 技術 | 說明 |
|---|---|---|
| 前端 | `public/index.html` 單一檔案 | 大會看板、排行榜、記分員端、管理後台 |
| 資料庫 | Supabase（專案 Rotary-3523，資料表前綴 `bowling_`） | 選手成績、設定、密碼、公告；前端只能讀，寫入一律經後端 |
| 即時同步 | Supabase Realtime + 每 30 秒輪詢備援 | 任一手機存檔，所有裝置 1~2 秒內更新 |
| 後端 | Vercel Serverless Functions（`api/*.js`） | 驗證密碼、寫入成績、名冊匯入、廣播、Gemini 拍照辨識 |
| AI 辨識 | Google Gemini（金鑰只存在 Vercel 環境變數） | 讀取計分螢幕照片的球道號碼、4 位選手總分、火雞、霸王花 |

## 角色與密碼（預設值，請上線前在管理後台更改）

| 角色 | 預設密碼 | 權限 |
|---|---|---|
| 管理計分員 | 2222 | 全部：手動改分、名冊匯入、設定、廣播、清空 |
| 助理計分員 | 3523 | 只能「拍照辨識 → 核對 → 儲存」該局分數與獎項 |
| 一般人 | 不需密碼 | 只能看大會看板與排行榜 |

密碼存在資料庫 `bowling_auth`，前端讀不到；QR Code 網址不夾帶密碼。

## 比賽規則實作

- 女子加分：每打完一局 +12（可在後台調整），三局最多 +36。
- 分區團體：各分區取加分後總分前 7 名加總；若前 7 名沒有女社員，以該分區最高分女社員取代第 7 名（看板與 Excel 均標示 ★）。
- 單局最高分：男女分組、各局分別計算（Excel「特別獎項名單」工作表）。

## 第一次部署（只需做一次）

```bash
npm install
bash setup/一鍵設定雲端.sh            # 建資料表 + 設定 Vercel 環境變數
bash setup/一鍵設定雲端.sh AIzaSy...  # 同上，並一併設定 Gemini 金鑰
vercel deploy                          # 預覽網址測試
vercel --prod                          # 正式網址
```

需要的 Vercel 環境變數：`SUPABASE_URL`、`SUPABASE_SECRET_KEY`、`GEMINI_API_KEY`（或舊名 `GEMINI_KEY`）。

## 比賽當天流程

1. 管理員進「管理後台」→ 上傳 Excel 名冊（欄位：球道、序號、所屬社、姓名、英文職稱、社名、性別、身份）。
2. 按「比賽開始，清空分數歸零」（需管理員密碼）。
3. 手機掃「QR Code → 現場計分員」，輸入密碼，選球道與局數，拍照辨識或手動輸入後儲存。
4. 大螢幕開「大會即時總表」，可開「大螢幕循環滾動」。
5. 賽後「下載 Excel」取得多工作表總成績單。
